Evendi

A modern web application designed to simplify event coordination and improve attendee engagement across teams and communities.

Visit Evendi Web App

Project Overview

Evendi is a polished event coordination web app built to help organizers manage schedules, invitations, and attendee engagement with ease. The platform delivers a seamless experience for planning events, sharing updates, and tracking participation across teams.

Key Features

  • Event creation and scheduling tools with easy-to-use forms and itinerary management.
  • Attendee RSVP tracking and automated email notifications.
  • Responsive interface that works smoothly on desktop, tablet, and mobile screens.
  • Interactive dashboards to monitor event metrics and guest participation in real time.
  • Secure access controls for organizers, staff, and attendees.

Technologies Used

HTML5 CSS3 JavaScript Bootstrap Responsive Design

My Role

I developed the frontend experience for Evendi, including the event dashboard, RSVP workflows, and responsive layout. I also implemented the interactive features that keep event organizers informed and attendees engaged, ensuring the app is easy to use across all devices.

Project Status

Current: Live and available at Evendi.ct.ws. The application is ready for recruiter review and demonstrates a professional event planning workflow with a polished user interface.

Challenges Solved

  • Streamlined event management workflows to reduce setup time.
  • Improved attendee communication with clear RSVP and notification functionality.
  • Ensured consistent display across browsers and device sizes.
  • Designed a refined UI that supports both event planners and guests.
