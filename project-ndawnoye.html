Ndawonye (Pty) Ltd

Secure authentication and authorization system with role-based access control for corporate clients.

Visit Live Site

Project Overview

Ndawonye (Pty) Ltd is a comprehensive web application focused on providing secure authentication and role-based access control. Built for businesses that need granular user permissions, this system ensures that employees, managers, and administrators each have tailored access to company resources while maintaining top-tier security standards.

Key Features

  • Secure authentication system with encrypted user credentials and session management.
  • Role-based access control (RBAC) allowing different permission levels for admins, managers, and regular users.
  • Responsive dashboard that adapts seamlessly to desktop, tablet, and mobile devices using Bootstrap.
  • Interactive UI components built with vanilla JavaScript for real-time data updates without page reloads.
  • Software consulting integration to tailor the solution to specific client business needs.

Technologies Used

HTML5 CSS3 JavaScript Bootstrap Software Consulting

My Role

As the lead developer on this project, I was responsible for implementing the complete authentication flow, including login validation, session persistence, and logout functionality. I designed and built the role-based permission system from scratch using JavaScript, ensuring that each user type sees only authorized content. Additionally, I collaborated with clients during the software consulting phase to understand their specific access control needs and translated those requirements into functional code. The responsive frontend was built using Bootstrap and custom CSS3, delivering a professional interface that works across all devices.

Project Status

Current: Ongoing development with active client collaboration. The core authentication and RBAC systems are fully functional, with additional features being added based on user feedback.

Challenges Solved

  • Implemented client-side route protection to prevent unauthorized page access.
  • Created dynamic UI rendering based on user roles without exposing sensitive logic.
  • Ensured secure storage of authentication tokens and user session data.
  • Optimized Bootstrap components for faster mobile load times.
