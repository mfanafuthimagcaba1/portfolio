Project Overview

This project was created to help event managers build, manage and promote their events easily. It includes user registration, access control, event scheduling, guest invitations, and dashboard analytics.

Key Features

  • Secure login and role-based access for administrators, organisers, and attendees.
  • Event creation and editing with detailed schedules and ticket options.
  • Real-time status updates and event attendance tracking.
  • Responsive UI for desktop and mobile users.

Technologies Used

React Node.js MongoDB

My Role

I worked on the frontend interface, authentication flow, and database integration. I also helped design the event dashboard and user experience for seamless navigation.
